One sharp, funny loading-screen tip for stressed developers and AI coding agents, 200 characters or fewer.

## Entry

> Context window at 98%? Congrats, your agent now remembers everything except what you actually asked for.

104 characters, one line: the agent's context window is nearly full, so it remembers everything except the actual request — the exact pain of building with an AI agent mid-build.

## Run

```sh
node main.ts
```

Writes the tip to `/output/entry.txt`. Node 24, standard library only, no network, no randomness — deterministic, two runs are byte-identical.
